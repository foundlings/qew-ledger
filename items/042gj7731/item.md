Owner (this session): 'build the diverged label' after: 'qews should filter these divergences from its boards they should have a special label like qew:diverged and drop out of the project boards and be filtered out. when in managed mode they should also get qew:managed removed.' An item with an open (non-claim) divergence for a target: its issue gets the label qew:diverged, its card is taken off the project board, and in overlay (managed) mode qew:managed is removed so the board views filtered on it drop the issue. Resolving the divergence (accept/reject or the default auto-settle) returns everything on the next sync. Closing is not part of this: an auto-settled divergence is undone by the same sync.
